# حافظ للإلكترونيات الحديثة

تطبيق إدارة متجر ونقطة بيع باللغة العربية، مبني باستخدام React وTypeScript وTailwind CSS.

## تشغيل المشروع

```bash
npm install
npm run dev
```

لفحص نسخة الإنتاج محلياً:

```bash
npm run build
npm run preview
```

## الحالة الحالية

- واجهة RTL متجاوبة ولوحة نظرة عامة.
- شاشة نقطة بيع تفاعلية ببيانات تجريبية (بحث المنتجات، سلة، كميات، خصم، وطباعة المتصفح).
- عرض مخزون وفواتير وواجهة متجر للمعاينة.
- لا يوجد اتصال بـ Supabase حالياً، ولا تُحفظ العمليات التجريبية بعد إعادة تحميل الصفحة.
- لا تضع مفاتيح Supabase في الكود أو المستودع. عند الربط ستُستخدم متغيرات بيئة عامة مناسبة للواجهة، وتبقى مفاتيح الخدمة السرية على الخادم فقط.

## ملاحظة

المبيعات والتقارير الظاهرة أرقام توضيحية وليست بيانات محاسبية فعلية.
